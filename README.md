## Overview

**Resumio** is a free, browser-based resume builder designed to make creating professional, ATS-friendly resumes simple and accessible.

It provides a focused editing experience with a live A4 preview and PDF export, allowing users to build, manage, and download multiple resume versions without registration or subscriptions.

## Features

- **No Sign-up Required** — Start building immediately without an account, email, or credit card.
- **Multiple Resumes** — Create and manage tailored resumes for different job opportunities.
- **Live A4 Preview** — See your resume update in real time as you edit.
- **Organized Editing** — Manage your information through ten focused sections.
- **Searchable PDF Export** — Download PDFs with selectable text and clickable links.
- **Browser-Based Storage** — Keep your resume library locally on your browser and device, without cloud synchronization.
- **ATS-Friendly Layouts** — Create clean, structured resumes designed with readability in mind.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/MohamedAyman-11/resumio-pro.git
```

2. Navigate to the project directory:

```bash
cd resumio-pro
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Privacy

Resumio does not require user registration or an account.

Resume data is stored locally in the browser, meaning your resumes remain on the browser and device where they were created. There is no cloud synchronization.
