# Resumio

### A resume that gets to the point.

Create a focused, professional resume with a live A4 preview and searchable PDF export.
Build tailored versions in your browser, without signing up.

<br />

[**Open Resumio**](https://resumio-pro.vercel.app/) &nbsp; · &nbsp; [View source](https://github.com/MohamedAyman-11/resume-builder)

</div>

---

## Features

- **Live A4 preview** — Review the document as you edit.
- **Guided resume sections** — Organize your profile, experience, education, skills, projects, and more.
- **Searchable PDF export** — Download selectable text with clickable links.
- **Multiple resume versions** — Keep tailored copies together in your browser.
- **Local data storage** — Resumes stay in your browser; no account or cloud sync is required.

## Built with

Next.js · React · TypeScript · Tailwind CSS · React PDF
