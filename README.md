## Features

- **Live A4 preview** as you edit
- **Ten guided sections** for experience, education, skills, projects, and more
- **Searchable PDF export** with selectable text and clickable links
- **Multiple resume versions** saved in your browser
- **No account or cloud sync** — your resume data stays in this browser
